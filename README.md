Retro Games Application

• Designed and built a Retro Games application in Python using CustomTkinter for a clean, user-friendly
interface and Pygame for game mechanics and animations.

• Included classic arcade games like Snake, Tetris, Flappy Bird, and Dino Run, integrated into a single
application for a seamless gaming experience.

• Developed each game individually, researching mechanics and logic from online resources and
implementing them to ensure smooth and enjoyable gameplay.

• Created menu, buttons, and navigation systems with CustomTkinter to allow users to switch between
games easily.

• Utilized Pygame to handle real-time interactions, animations, collisions, scoring, and controls.

• Used Random, Time, OS, and Math libraries to manage dynamic game behavior, timing, and resources.

• Tackled challenges with multiple dependencies and researched how to package the application to run
reliably on different machines.

• Gained hands-on experience in combining creativity, programming, and problem-solving to deliver a
functional and interactive retro gaming application.



Retrogames.py is the main file in the main folder, with all dependencies in its assets subfolder. Games can be controlled via arrow keys, WASD, or mouse, with some games listing specific controls.
